Add a course for everyone

  1. Build it in Tentaplugg Studio in Claude, then press Export for website.
  2. In this site's GitHub repository, open the courses folder → Add file → Upload files, drop the file in and press Commit changes.
  3. Within a few minutes it shows up on this page.
